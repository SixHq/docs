Sixth works by calling tools: reading files, editing code, running commands, browsing, delegating to agents and more. Each tool use appears in the chat as a compact row you can expand to see the details: diffs, command output, search results, images.

Depending on your [auto-approve](/features/auto-approve) settings, a tool either runs straight away or shows an approval card with **Run** / **Reject** (press **Enter** to approve or **Esc** to reject).

## Reading & exploring code

| Tool | What it does |
| --- | --- |
| `read_file` | Reads a file. Extracts the text from PDF and DOCX files too. |
| `read_batch` | Reads several files at once (much faster than one by one). A line can also start with `list:` to list a folder or `defs:` to list the code definitions in it. |
| `read_file_in_chunks` | Reads a very large file in 500 KB chunks. Plain reads are capped at 5 MB, so larger files are read this way. |
| `list_files` | Lists a folder's contents, top level or recursively. |
| `search_files` | Regex search across files, with surrounding context lines. |
| `list_code_definition_names` | Lists the classes, functions and methods defined in a folder's source files. |

## Editing files

| Tool | What it does |
| --- | --- |
| `write_to_file` | Creates a file or overwrites it with complete new content. |
| `append_to_file` | Adds content to the end of a file, used to write very large files in parts. |
| `replace_in_file` | Makes targeted edits with SEARCH/REPLACE blocks. |
| `delete_file` | Deletes a file, for example a temporary script. |
| `create_svg_or_dot_ico` | Creates or edits `.svg` and `.ico` files directly. The chat shows a live preview. |

Every edit shows a diff in the chat. With [checkpoints](/features/checkpoints) you can compare or roll back any step.

## Terminal

| Tool | What it does |
| --- | --- |
| `execute_command` | Runs a terminal command. Commands that start a server or watcher run as [background shells](/features/background-shells). |
| `access_launched_terminal_task` | Checks a background shell: whether it's running, its pid, exit code, uptime and latest output. |
| `wait_until` | Pauses for 1–300 seconds, for example while a build or server starts. |

## Web, images & browser

| Tool | What it does |
| --- | --- |
| `web_search` | Searches the web for current information, docs or error solutions. |
| `web_fetch` | Fetches a web page and converts it to markdown. |
| `view_image` | Fetches an image from a URL so Sixth can look at it. |
| `generate_image` | Generates a custom image (logo, background, design asset) and saves it to your project. Also available as `/generate-image`. |
| `browser_action` | Drives a browser: launch a URL, click, type, scroll and take screenshots to test what it built. See [Remote Browser Support](/exploring-sixth-tools/remote-browser-support). |

## Design

| Tool | What it does |
| --- | --- |
| `launch_design_studio` | Opens [Design Studio](/features/design-studio) so you can pick a designer-made theme before Sixth builds a frontend. Also available as `/design-studio`. |
| `get_design_spec` | Loads the full build brief for a Design Studio design: tokens, fonts, layouts, voice, imagery and motion rules. |

## Agents & skills

| Tool | What it does |
| --- | --- |
| `spawn_agents` | Runs 1–5 [sub-agents](/features/sub-agents) in parallel on independent parts of a task, then gathers their results. |
| `launch_agent` | Hands a task to one of your [background agents](/features/background-agents). It returns right away and the result arrives later. |
| `get_dedicated_agent_progress` | Checks the status, recent activity and result of background agent runs. |
| `stop_dedicated_agent` | Stops a background agent run. You can resume it later from the Agents dock. |
| `use_skill` | Loads a [skill](/features/skills)'s full instructions when it's relevant or when you call it with `/skill-name`. |

## MCP

| Tool | What it does |
| --- | --- |
| `use_mcp_tool` | Calls a tool on a connected [MCP server](/mcp/mcp-overview). |
| `access_mcp_resource` | Reads a resource from a connected MCP server. |
| `load_mcp_documentation` | Loads instructions for building or installing an MCP server. |

## Conversation & task flow

| Tool | What it does |
| --- | --- |
| `ask_followup_question` | Asks you a question, optionally with 2–5 answers you can pick (press 1–N to choose). |
| `plan_mode_respond` | Replies in Plan mode, used to discuss and agree on an approach before any changes. |
| `explore_mode_respond` | Replies in Explore mode, which is for deep investigation of a codebase. |
| `attempt_completion` | Presents the finished result. It can include a command to show it, such as opening the page Sixth built. |
| `new_task` | Starts a new task that carries a summary of the current one (`/newtask`). |
| `condense` | Summarises the conversation to free up context (`/smol`). |
| `report_bug` | Drafts a GitHub issue (`/reportbug`). |
