### Install the extension

**VS Code Marketplace (recommended)** — works in VS Code and Cursor:

1. Open the Extensions view (`Cmd + Shift + X` on macOS, `Ctrl + Shift + X` on Windows/Linux).
2. Search for **Sixth** and install **Sixth AI** (publisher `Sixth`), or open the [marketplace page](https://marketplace.visualstudio.com/items?itemName=Sixth.sixth-ai) and click **Install**.
3. Click the Sixth icon in the Activity Bar to open the chat. To give it more room, run **Sixth: Open In New Tab** from the command palette (`Cmd/Ctrl + Shift + P`).

**Open VSX** — for VS Code-compatible editors without Marketplace access (VSCodium, Windsurf): open the Extensions view, search for **Sixth**, install it and reload if prompted.

<Tip>If the Sixth icon doesn't appear after installing, reload the window (`Developer: Reload Window`).</Tip>

### Sign in

1. In the Sixth panel, click **Get Started for Free**.
2. Your browser opens [app.trysixth.com](https://app.trysixth.com) to create an account or sign in. No credit card is needed for the free plan.
3. When you finish, the browser hands you back to VS Code and Sixth is ready.

If the browser doesn't open, click **Copy Sign-in URL** and paste it into your browser yourself. If you already signed in from another VS Code window and Sixth still shows the sign-in screen, use the button in the **Troubleshooting** section to pick up your existing session.

Once you're signed in, every supported model works through your Sixth account. You can also [bring your own API keys](/getting-started/model-selection-guide#bring-your-own-key) for specific providers.

### Your first task

Type what you want into the message box and press Enter. For example:

```
Create a folder called hello-world with a single web page that says "Hello World" in big blue text, then open it in the browser.
```

Sixth will show each step as it goes: files it reads and creates, commands it runs, and an approval card whenever it needs your OK. See [The chat interface](/features/chat-interface) for a full tour.

### Tips

- **Mention context.** Type `@` to attach files, folders, problems or URLs to your message.
- **Paste screenshots.** Sixth can read images, including error screenshots and designs.
- **Paste errors.** Drop error messages straight into the chat.
- **Pick a mode.** Use [Plan, Act or Explore](/features/plan-and-act) depending on whether you want a plan, the change itself, or an explanation of the codebase.
