Sixth works with the leading frontier models. On a Sixth plan they all run through your Sixth account, so you can switch freely without setting up API keys.

## Switching models

Click the model name in the bottom row of the message box (next to the **Act** mode button). A picker opens above the message box:

- **Search** by name, or browse models grouped by provider.
- Models marked **New** were added recently; **Popular** marks what most people use. The check mark shows your current model.
- Use `↑` `↓` to move, `Enter` to pick, `Esc` to close.
- The **Image** tab lists the image models Sixth can use for [image generation](/features/image-generation).

Your choice applies to new requests straight away, including in the middle of a task.

## Extended thinking

Models that support extended thinking (shown with a lightbulb) let you turn reasoning on when you pick them. Choosing one opens a small panel with a **thinking** switch; turn it on and click **Use** to select the model with thinking enabled. Some models, such as Fable 5.1, always think.

While a model is thinking you'll see a live **Thinking** row in the chat; afterwards it collapses to **Thought for Ns**, and you can click it to read the reasoning.

## Choosing a model

- **Hard, multi-step coding work:** a top-tier model such as Claude Opus 5.5, Fable 5.1, GPT-6 Astra or Gemini 3.1 Pro.
- **Fast everyday edits:** a quicker model such as Gemini 3.8 Flash, DeepSeek V4.1 Flash, Claude Haiku 4.5 or Kimi K3.
- **Planning:** pair [Plan mode](/features/plan-and-act) with a strong reasoning model and turn thinking on.

You can switch at any point, so it's easy to plan with one model and implement with another.

## Context window

Each model has a context window: how much of the conversation, files and tool output it can hold at once. The ring next to the task title shows how much of it the current task is using. When a long task gets close to the limit, Sixth compacts the conversation automatically so you can keep going. See [Understanding context management](/getting-started/understanding-context-management).

## Bring your own key

If you'd rather use your own provider account, pick a model whose provider isn't set up yet. It shows an **Add key** badge, and selecting it opens an inline form for your API key (with a link to get one, plus a base URL field where relevant). Click **Save & use** and the model runs on your key from then on.

You can manage provider keys later in **Settings**. Setup guides for each provider are under [Provider Configuration](/provider-config/anthropic), and local models are covered in [Running models locally](/running-models-locally/read-me-first).
